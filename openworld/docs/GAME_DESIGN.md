# 에버린: 잊힌 봉화 — 기획서

> 로우폴리 오픈월드 액션 RPG · 모바일(가로 화면) · Godot 4

## 1. 한 줄 소개
꺼져버린 일곱 봉화를 다시 밝히기 위해, 떠돌이 기사 **카엘**이 섬 대륙 에버린을 가로지른다.

## 2. 세계관
- 에버린은 일곱 봉화의 불빛으로 지켜지던 섬 왕국이었다.
- 어느 밤 봉화가 동시에 꺼졌고, 그 뒤로 고블린 약탈자와 굶주린 늑대가 들판을 차지했다.
- 봉화마다 그것을 지키도록 만들어진 **바위 골렘(봉화의 수호자)**이 깨어나 아무나 다가오지 못하게 막는다.
- 봉화를 하나씩 되살릴 때마다 하늘로 빛기둥이 솟고, 그곳이 카엘의 새 거점(부활 지점)이 된다.

## 3. 맵 (지름 약 3.2km 섬)
| 지역 | 특징 |
|---|---|
| 새벽 언덕 (중앙) | 시작 지점. 완만한 초원, 적이 나오지 않는 안전지대 |
| 숲 지대 | 참나무·소나무·자작나무 숲. 늑대 무리가 많음 |
| 평원 | 고블린 약탈자 무리 |
| 산맥 | 높이 80m 이상 설산. 꼭대기에서 망토로 활공해 빠르게 이동 |
| 해안 | 모래사장과 바다. 수영 가능, 오래 헤엄치면 기력 소모 |
| 봉화 7곳 | 섬 둘레를 고르게 둘러쌈. 시작 지점에서 멀수록 적 레벨이 높음 |

지형은 시드 값 하나로 계산하는 노이즈 공식이라 맵 데이터 파일이 필요 없다.
플레이어 주변 48m 조각(청크)만 실시간으로 만들고 지우기 때문에 휴대폰 메모리 부담이 적다.

## 4. 캐릭터 디자인

### 카엘 (주인공)
- **컨셉**: 몰락한 기사단 출신 떠돌이 기사. 말수는 적지만 봉화를 되살리겠다는 의지가 강하다.
- **외형**: 갈색 머리, 오른쪽 뺨에 흉터 하나. 붉은 튜닉 위에 가죽 흉갑을 입고, 은빛 견갑·팔목·무릎 보호대를 찼다. 금색 버클 벨트, 끝단에 금색 장식이 있는 **붉은 망토**를 둘렀다.
- **무기**: 금색 가드가 달린 장검.
- **특징**: 망토를 펼쳐 날개처럼 **활공**한다. 상징색은 붉은색과 은색.

### 고블린 약탈자
- 작고 등이 굽은 초록 피부의 약탈자. 옆으로 뻗은 큰 귀, 노란 눈, 매부리코.
- 누더기 천을 걸치고, 쇠 가시를 박은 나무 몽둥이를 든다.
- 2~3마리가 무리 지어 다니며, 내려치기 전에 몽둥이를 크게 치켜든다(예고 동작).

### 잿빛 늑대
- 회색 털과 짙은 갈기, 주황색 눈. 빠르게 달려와 물고 튀어 오른다.
- 숲 지대에 많이 나온다. 체력은 낮지만 빠르다.

### 바위 골렘 — 봉화의 수호자 (중간 보스)
- 키 3.5m 정도의 돌 거인. 어깨와 머리에 이끼가 덮였고, 눈과 가슴의 룬이 푸른빛으로 빛난다.
- 두 주먹을 높이 들었다가 내려찍는다. 동작이 느린 대신 한 방이 강하다. 구르기로 피하는 것이 핵심이다.

## 5. 조작 (모바일)
| 위치 | 기능 |
|---|---|
| 화면 왼쪽 아무 곳 | 손가락을 대면 그 자리에 조이스틱이 생겨 이동 |
| 화면 오른쪽 드래그 | 카메라 회전 |
| 공격 (큰 빨간 버튼) | 연타하면 3단 콤보: 내려베기 → 가로베기 → 회전베기 |
| 점프/활공 | 땅에서 누르면 점프, 공중에서 누르면 망토 활공을 켜고 끈다 |
| 구르기 | 잠깐 무적이 되어 공격을 피한다 (기력 20) |
| 질주 | 누르고 있는 동안 빨리 달린다 (기력 소모) |
| 확인 | 봉화 근처에서만 나타난다 |

PC 테스트용 키보드 조작: WASD 이동, 마우스 드래그로 카메라, Space 점프/활공, J 공격, K 구르기, Shift 질주, E 상호작용.

## 6. 핵심 시스템
- **전투**: 공격하면 가까운 적 쪽으로 자동 조준한다(모바일 편의). 치명타 12%. 적은 공격 전에 예고 동작을 하고, 그 순간 사거리 밖에 있거나 구르는 중이면 공격이 빗나간다.
- **성장**: 적을 처치하면 경험치와 골드를 얻는다. 레벨이 오르면 최대 체력·기력·공격력이 오르고 체력이 전부 회복된다.
- **기력**: 질주, 활공, 구르기, 수영에 쓰인다. 쓰지 않으면 0.8초 뒤부터 다시 찬다. 물에서 기력이 바닥나면 체력이 깎인다.
- **봉화**: 근처로 가면 수호자 골렘이 나타난다 → 골렘을 쓰러뜨린 뒤 '확인' 버튼 → 빛기둥이 솟고 부활 지점이 된다.
- **레이더**: 화면 오른쪽 위. 노란 점은 밝히지 않은 봉화, 주황 점은 밝힌 봉화, 빨간 점은 적이다. 범위 밖 봉화는 테두리에 화살표로 표시한다.
- **낮과 밤**: 하루가 12분이다. 해질녘에는 노을이 지고, 밤에는 밝힌 봉화의 빛기둥이 더 잘 보인다.
- **저장**: 15초마다, 봉화를 밝힐 때, 앱이 백그라운드로 갈 때 자동 저장한다.

## 7. 아트 방향
- **로우폴리 + 플랫 셰이딩**: 텍스처 없이 면마다 단색을 칠한다. 휴대폰에서 가볍고 일관된 스타일이 나온다.
- 지형 색은 높이·경사·숲 밀도에 따라 자동으로 정해진다(모래 → 초원 → 숲 → 바위 → 만년설).
- 모든 캐릭터·소품은 코드(`scripts/models/`)로 조립한다. 나중에 Blender로 만든 모델(.glb)로 하나씩 바꿀 수 있다.

## 8. 콘텐츠 (v0.2)

### 마을 "새벽 마을" (시작 지점)
집 여섯 채, 우물, 시장 좌판, 대장간, 경비 초소, 울타리, 밤에 켜지는 등불이 있다.

| NPC | 역할 |
|---|---|
| 촌장 하든 (흰 수염, 지팡이) | 메인 퀘스트, 보물상자 퀘스트 |
| 상인 미라 (챙 넓은 모자) | 상점(물약·장비 구매, 전리품 판매), 채집 퀘스트 |
| 대장장이 고르 (앞치마, 망치) | 제작(레시피 8종), 장비 강화 +1~+5, 재료 납품 퀘스트 |
| 경비대장 브란 (투구, 창) | 토벌 퀘스트(고블린, 우두머리, 해골, 오우거) |

NPC 머리 위의 **!**는 받을 수 있는 퀘스트, **?**는 보고할 퀘스트를 뜻한다.

### 퀘스트 13개
- **메인 5개**: 촌장과 대화 → 봉화 1개 → 3개 → 5개 → 7개(보상: 전설 무기 "새벽의 검")
- **서브 8개**: 약탈자 소탕, 고블린 우두머리, 밤의 망자들, 산의 폭군(오우거), 늑대 가죽 주문, 광석 납품, 약초 심부름, 멧돼지 엄니, 보물 사냥꾼
- 화면 왼쪽에 추적 중인 퀘스트가 표시되고, 레이더와 지도에 **★** 목표 위치가 나온다.

### 아이템 28종 (등급: 일반·고급·희귀·영웅·전설)
- **소비 5종**: 체력 물약, 큰 체력 물약, 기력 물약(20초 무한 기력), 구운 고기, 용기의 영약(공격력 +30%)
- **재료 9종**: 고블린 귀, 늑대 가죽, 날고기, 멧돼지 엄니, 뼛가루, 약초, 철광석, 골렘 핵, 오우거 뿔
- **무기 6종**: 낡은 장검 → 강철 장검 → 기사단 장검 → 족장의 대검 / 불꽃의 검 → 새벽의 검
- **방어구 5종**: 여행자의 옷 → 늑대가죽 갑옷 → 사슬 갑옷 → 기사 판금 갑옷 → 수호자의 갑주
- **장신구 3종**: 구리 반지, 늑대 이빨 목걸이, 불씨 반지
- 장비를 바꾸면 카엘의 겉모습도 바뀐다: 튜닉·망토 색, 판금 흉갑, 칼날 색과 길이.

### 몬스터 7종 + 정예
| 몬스터 | 출현 | 특징 |
|---|---|---|
| 고블린 약탈자 | 평원·야영지 | 2~3마리 무리 |
| 고블린 우두머리 | 고블린 야영지 | 뿔 투구, 양손 내려치기 |
| 잿빛 늑대 | 숲 | 빠름, 물고 튀어오름 |
| 성난 멧돼지 | 평원 | 노려보다가 **돌진** |
| 해골 전사 | **밤에만**, 폐허 | 녹슨 검과 방패, 해가 뜨면 사라짐 |
| 봉화의 수호자 (골렘) | 봉화 | 중간 보스 |
| 오우거 족장 | 산속 동굴 | 체력 900, 거대한 대검 |

필드 몬스터의 6%는 **[정예]**로 나온다. 정예는 크고, 체력 2.5배, 경험치 3배이며 장비를 잘 떨어뜨린다. 보스와 정예에게는 화면 위에 체력바가 뜬다.

### 탐험
- **몬스터 거점 13곳**: 고블린 야영지 8곳(4곳에 우두머리), 망자의 폐허 3곳, 오우거 동굴 2곳. 적을 모두 처치하면 보물상자를 열 수 있다.
- **채집**: 들판의 약초, 산기슭의 반짝이는 철광맥
- **전리품**: 처치한 적에게서 주머니와 골드가 튀어나오고, 가까이 가면 빨려 들어온다. 희귀 등급 이상은 빛기둥이 솟는다.
- **빠른 이동**: 지도에서 밝힌 봉화를 누르면 그곳으로 순간이동한다.

### 메뉴와 연출
- **타이틀 화면**: 이어하기, 새 게임
- **메뉴 5탭**: 가방(분류·사용·장착), 장비(3D 미리보기와 능력치), 퀘스트, 지도, 설정(감도·음량·시야 거리·그림자·FPS)
- **소리**: 효과음 20종과 배경음악 2곡. 모두 코드로 합성했다(`tools/gen_audio.py`).
- **연출**: 레벨업·퀘스트 완료·장소 발견 배너, 획득 알림, 피격 시 붉은 화면, 낮/밤 시계
