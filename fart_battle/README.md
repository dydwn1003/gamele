# 방귀 대결! 뿌앙 리그

엉덩이를 맞댄 동물들이 무지개빛 **방귀 빔**을 쏘아 가운데서 맞부딪히는 코믹 대전 게임.
Godot 4.4 (GDScript, 2D, GL Compatibility), 세로 720x1280, 그래픽·효과음 모두 코드로 생성.

## 플레이
- **뿡 버튼**을 꾹 누르면 압력이 차고, 떼면 방귀 빔! 게이지가 **초록 구간**일 때 떼면 「완벽한 뿡」(파워 ×1.6, 무지개 빔)
- 너무 오래 참으면 **삐끗** → 기절 + 빔이 나에게 밀려옴
- **코 막기**: 상대 빔 대부분을 막음. 상대가 뀌기 직전(0.3초 이내)에 막으면 **튕겨내기**
- 경기 중 나오는 **음식**을 탭: 매운 고추(불꽃 빔), 고구마(파워), 콩(가스), 삶은 계란(냄새 지속),
  탄산음료(빨리 참), 양배추(가스 충전 2배), 우유(초강력 아니면 배탈)
- 빔이 부딪히는 지점을 **상대 엉덩이까지 밀면 라운드 승리**, 3판 2선승
- 모드: **혼자 하기**(상대 5명 리그: 꼬마 다람쥐 → 멧돼지 할매 → 헬스 고릴라 → 스컹크 박사 → 하마 대왕),
  **둘이서 대결**(폰 하나를 위아래로 잡고, 멀티터치)

## 실행 / 테스트 / 빌드
```bash
cd fart_battle
bash tools/test.sh          # 헤드리스 테스트 (Godot 자동 설치)
bash tools/screenshots.sh   # 자동 플레이 스크린샷 → screenshots/
bash tools/build_web.sh     # build/web (일반 호스팅), build/artifact (claude.ai 아티팩트용)
```
PC 에서는 마우스 클릭이 터치로 동작하고, 스페이스 = 뿡, B = 코 막기.

## 구조
- `scripts/core/battle_logic.gd` 규칙(순수 로직) · `scripts/ai/ai_controller.gd` 컴퓨터 상대
- `scripts/battle/` 대결장(arena), 동물(critter), 조작부(pad), 대결 흐름(battle)
- `scripts/audio/fart_synth.gd` 방귀 효과음 합성 · `scripts/core/save.gd` 리그 진행/전적 저장
- `data/*.json` 캐릭터·음식·밸런스 수치 (코드 수정 없이 조정)

## HTML 버전 (Godot 없이 바로 실행)

`web/fart_battle.html` 하나만 브라우저로 열면 됩니다 (인터넷 없으면 기본 글꼴로 표시).
규칙은 `scripts/core/battle_logic.gd` 를 JavaScript 로 옮긴 것이고, 수치는 `data/*.json` 에서 가져옵니다.
수치나 `web/template.html` 을 고치면 `bash tools/build_html.sh` 로 다시 만드세요.

### HTML 버전 전용 (아직 Godot 버전에는 없음)
- 필살 게이지: 완벽한 뿡 +34, 맞히기 +8, 튕겨내기 +25. 꽉 찬 뒤 다음 완벽한 뿡이 필살기
  (파워 ×2, 튕겨내기 불가, 막아도 절반만 줄어듦, 컷인 연출). 수치는 `data/balance.json` 의 `special_*`.
- 이펙트: 나선이 감기는 물줄기형 빔, 모으기 오라·완벽 구간 반짝임, 충돌 섬광·물보라, 충격파 고리,
  큰 방귀 타격 경직·줌, KO 슬로모션, 탄산 먹으면 파란 거품 빔.
- 45도 무대: 내 동물은 앞(왼쪽 아래), 상대는 뒤(오른쪽 위). 빔이 대각선으로 원근 굵기를 갖고 날아감.
- 카메라 샷: 강한 방귀는 맞는 쪽으로 당겨 기울이고, 필살은 쏘는 쪽에서 맞는 쪽으로 훑고, KO 는 진 쪽 클로즈업. 반달 모양 충격 궤적.
- 코 막기 연출: 큰 빨래집게, 눈 질끈·볼 빵빵 표정, 엉덩이 앞 "냄새 금지" 방패, 막을 때 물보라 튕김·"냄새 차단!", 튕겨내기는 분홍 방패 + 카메라 샷.
- 힘겨루기: 두 빔(세기 0.4 이상)이 정면으로 부딪히면 시작. 시작 위치 = 에너지(빔 세기 × (0.6 + 0.4 × 남은 가스/100)) 차이.
  3박자 동안 바깥 원이 안쪽 원에 맞닿을 때 탭(완벽 ×1.6 / 좋아 ×1.0 / 놓침 ×0.4, 탭마다 가스 6, 부족하면 절반). 이긴 쪽은 상대 빔을 끊고 크게 밀어내며 상대 기절, 차이가 작으면 상쇄. 수치는 `clash_*`.

## 온라인 대전 (HTML 버전, `server/`)

빠른 매칭(아무나), 공개방(로비 목록에 보임), 비밀방(코드), 친구 초대(공유창·링크 복사·QR), 재경기.

```bash
cd fart_battle/server && npm install && npm start   # http://localhost:8080 접속
```

- 서버는 게임 페이지(`web/fart_battle.html`)도 같이 내려줘서 주소 하나로 끝납니다. 홈 화면에 추가하면 앱처럼 열려요(manifest).
- 구조: 서버는 로비·매칭·메시지 중계만, 규칙 계산은 방장 브라우저. 손님은 입력만 보내고 방장이 초당 25번 상태를 보냄.
  손님 화면은 좌우를 바꿔 그려서 둘 다 자기 동물이 앞에 보임.
- 공정한 타이밍: 손님의 방귀는 "누른 시간", 힘겨루기 탭은 "목표에서 어긋난 시간"을 손님 폰에서 재서 보냄.
  방장은 힘겨루기 박자마다 손님 탭을 최대 0.45초 더 기다림.
- 배포: 저장소 루트의 `render.yaml` (Render 무료 플랜, 직접 배포는 아직 안 해봄). 다른 곳도 `npm start` + `PORT` 환경변수면 됨.
- 테스트용 지연: `RELAY_DELAY_MS=75 npm start` (중계 메시지를 일부러 늦게 보냄).
- 파일/claude.ai 아티팩트로 열면 온라인 버튼은 안내만 나옵니다 (서버 주소에서만 동작).

## 리그 (12판, 4챕터)

| 챕터 | 배경 | 상대 (마지막 = 보스) |
|---|---|---|
| 1 햇살 숲 | 숲·낙엽 | 꼬마 다람쥐 → 멧돼지 할매 → **헬스 고릴라** |
| 2 달밤 늪 | 달·반딧불·물웅덩이 | 꿀꿀 돼지 → 스컹크 박사 → **하마 대왕** |
| 3 눈꽃 산 | 설산·전나무·눈 | 펭귄 형제 → 눈다람쥐 닌자 → **북극곰 장군** |
| 4 불꽃 화산 | 화산·용암·불씨 | 화산 멧돼지 → 용암 불곰 → **전설의 방귀왕** |

난이도는 컴퓨터 대리 플레이어 3단계(보통/잘함/고수)로 상대마다 수십 판씩 돌려 맞춤.
고수 기준 승률: 100 → 100 → 95 → 90 → 80 → 70(보스) → 82 → 74 → 46(보스) → 52 → 40 → 20(최종 보스).
새 동물(돼지·펭귄·곰)과 배경은 HTML 버전에만 그림이 있음 (Godot 버전은 기본 모양으로 보임).

## 캐릭터 선택과 특성 (HTML 버전)

처음엔 뿌앙이만, 리그에서 이긴 상대는 내 캐릭터로 해금. 혼자 하기·둘이서(1P/2P 각자)·온라인 모두 선택 가능.
플레이어로 쓸 땐 `play` 능력치(균형), 리그 상대로 나올 땐 위쪽 능력치(난이도용) + 같은 특성.

| 캐릭터 | 특성 |
|---|---|
| 두더지 뿌앙이 | 넓은 손맛: 완벽 구간이 넓음 |
| 꼬마 다람쥐 | 도토리 저장: 음식 먹으면 가스 +15 |
| 멧돼지 할매 | 한 방: 압력 80% 이상이면 파워 +20% |
| 헬스 고릴라 | 연사: 압력 15% 빨리 참, 회복 빠름 (파워 약함) |
| 꿀꿀 돼지 | 먹방: 음식 먹으면 필살 +20 |
| 스컹크 박사 | 독가스: 맞힌 방귀 냄새가 계속 밀어냄 |
| 하마 대왕 | 철벽 엉덩이: 코 막기 90%, 튕겨내기 +0.1초 |
| 펭귄 형제 | 미끄럼 연발: 가스 소모 -20% |
| 눈다람쥐 닌자 | 그림자 막기: 코 막기 대기 -40% |
| 북극곰 장군 | 눈사태: 힘겨루기 에너지 +25% |
| 화산 멧돼지 | 마그마: 4번째 방귀마다 불꽃 빔 |
| 용암 불곰 | 참을성: 과충전 여유 2.5배, 삐끗 기절 절반 |
| 전설의 방귀왕 | 왕의 위엄: 필살 게이지 1.5배 |

밸런스: 같은 실력 컴퓨터끼리 각 캐릭터 vs 뿌앙이 120판 → 모두 승률 40~60%.

## 스테이지 기믹 · 별 · 코인 · 상점 (HTML 버전)

- 기믹: 숲 바람(2.5초 동안 구름을 한쪽으로), 달밤 달빛(4초 동안 그쪽 방귀 +25%), 눈산 빙판(밀림이 1.6배 미끄러짐),
  화산 분출(경고 1.4초 안에 코 막기 하면 무사, 아니면 기절 0.6초 + 밀림). 수치는 `balance.json` 의 wind_/moon_/ice_/erupt_*.
  둘이서·온라인은 배경이 무작위라 기믹도 함께 바뀜.
- 별 3개: 승리 / 완벽한 뿡 3번 이상 / 한 라운드도 안 지기. 코인: 리그 승리 30 + 별당 10 (+첫 승리 50), 패배 5, 온라인 승 20·패 5.
- 상점: 빔 색 6종, 모자·소품 6종. 장착하면 리그·둘이서(1P)·온라인(상대에게도 보임)에 적용.

## 방귀 VFX (HTML 버전)

- 시작할 때 노이즈로 연기 스프라이트 4종·에너지 결 무늬·렌즈 플레어를 구워 두고, 색별로 물들인 것을 캐시.
- 방귀 한 방: 분사구 섬광 + 플레어, 굴절처럼 보이는 충격파(밝은 고리 + 안쪽 어두운 고리), 원뿔 모양 연기 폭발, 모션블러 불꽃.
  크기에 따라 양이 달라지고, 작은 "뽁"은 연기 도넛. 빔: 블룸, 안에서 흐르는 에너지 결, 끝의 빛나는 머리, 가장자리 연기 꼬리, 반짝이.
- 연기는 캐릭터 뒤, 빛·불꽃은 앞. 프레임이 느리면 자동으로 이펙트 양을 줄임(VQ 0.35~1).

## 재미 요소 (HTML 버전)

- **뿡 챌린지 런**: 1판 승부로 계속 다음 상대, 이길 때마다 강화 카드 3장 중 1장(12종), 목숨 2개(카드로 최대 3).
  12단계 이후로는 상대가 계속 강해짐. 최고 단계 기록·코인.
- **보스 특수 패턴**: 헬스 고릴라 3연발, 하마 대왕 냄새 장벽(4.5초 동안 내 방귀 위력 절반, 필살은 뚫음),
  북극곰 장군 눈보라(압력 게이지가 서리로 가려짐), 전설의 방귀왕 2페이즈(한 라운드 지면 변신: 파워 +20%, 세 패턴을 섞어 씀). 1초 경고 후 발동.
- **관중 + 도발**: 무대 뒤 관중이 큰 방귀에 환호하고 냄새가 오면 코를 막음. 조작부 「메롱~ / 뿡뿡! / 흥!」 말풍선(1.2초 대기, 온라인 상대에게도 보임, 컴퓨터도 가끔 도발).
- **방귀 로켓**: 꾹 눌렀다 떼서 발사(초록 구간이면 완벽 발사 ×1.25), 공중에서 탭하면 부스트 3번, 공중 음식(고추 큰 부스트·탄산 부스트+1·우유 복불복). 거리 기록·코인.
