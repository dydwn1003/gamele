# 고양이 마당 (gamele)

넓은 마당을 자유롭게 돌아다니는 고양이를 밥도 주고 쓰다듬으며 키우는
오픈필드 2D 도트(픽셀 아트) 게임입니다. 마당에는 4개의 서로 다른 구역과
숨은 동물 친구, 반짝이는 보물이 있어 탐험하는 재미를 더합니다.

## 스택

- Expo (React Native, TypeScript) — 모바일/웹 공용
- `@react-native-async-storage/async-storage` — 친밀도/포만감/애정도 로컬 저장
- `expo-linear-gradient` — 배경 그라디언트
- 순수 React state + `setInterval` 기반 게임 루프 (별도 게임 엔진/캔버스 라이브러리 없이 View만으로 구현)

## 게임 방식

1. 화면 왼쪽 아래 가상 조이스틱을 드래그해 고양이를 마당 어디로든 자유롭게 이동시킵니다.
2. 이동 방향에 맞춰 고양이가 네 다리로 걷는 애니메이션(2프레임 대각선 보행)을 재생하고,
   왼쪽/오른쪽으로 갈 때 스프라이트가 좌우로 뒤집힙니다.
3. 마당 곳곳에 생선 간식이 주기적으로 나타납니다 — 고양이가 간식 위로 지나가면
   자동으로 먹고 **포만감**이 오르고 **애정도**도 조금 오릅니다.
4. 고양이를 직접 탭하면 쓰다듬기 동작(하트 이펙트)과 함께 **애정도**가 오릅니다.
5. 애정도가 가득 차면 **친밀도 레벨**이 오르며, 포만감/애정도는 시간이 지나면 서서히
   줄어들어 계속 신경 써서 돌봐줘야 합니다.
6. 마당은 4개의 구역(포근한 마당 / 꽃밭 / 그늘진 숲 / 모래 언덕)으로 나뉘어 있고,
   새 구역에 들어가면 이름이 표시됩니다.
7. 구역 곳곳에 강아지·햄스터 친구가 숨어 있습니다 — 가까이 다가가면 처음 한 번
   인사를 나누고 친구가 되며(애정도 보너스), **이야기** 버튼에서 지금까지의
   이야기를 다시 볼 수 있습니다.
8. 반짝이는 보물 6개가 마당 곳곳에 숨어있습니다. 전부 찾으면 고양이가 예쁜
   리본을 얻습니다.
9. 진행 상황(친밀도/애정도/포만감/만난 친구/모은 보물)은 자동 저장되어 앱을
   다시 열어도 이어집니다.

## 코드 구조

- `src/pixel/` — 도트 스프라이트 시스템. `mirror.ts`가 좌우 대칭 장식(꽃/덤불/나무/
  연못/보물)을 절반만 손으로 작성해 자동으로 완성해주고, `sprites.ts`에는 옆모습으로
  걷는 고양이(2프레임)와 그 뼈대를 재활용해 배색만 바꾼 강아지·햄스터 NPC, 생선
  간식, 꽃 3종, 덤불·나무·연못·보물·리본 도트 데이터가 있습니다. `PixelGrid.tsx`가
  이를 실제 픽셀 사각형들로 렌더링합니다.
- `src/game/` — 게임 규칙.
  - `world.ts`: 마당 크기, 4개 구역 정의, 배경 장식/NPC/보물 배치
  - `fieldEngine.ts`: 순수 함수 기반 상태 전이 — 조이스틱 입력에 따른 이동/애니메이션,
    포만감·애정도 감소, 간식 스폰과 충돌 판정, 쓰다듬기, 친밀도 레벨업, 구역 전환·
    NPC 인사·보물 획득 이벤트 생성
  - `story.ts`: 만난 친구·모은 보물에 따라 이야기 로그를 구성
  - `useGameLoop.ts`: 60fps 틱 훅
  - `save.ts`: AsyncStorage 저장/불러오기 (친밀도/애정도/포만감/만난 친구/모은 보물)
- `src/components/Joystick.tsx` — 가상 조이스틱 컨트롤
- `src/screens/` — `HomeScreen`(시작 화면), `FieldScreen`(마당 플레이 화면: 카메라가
  고양이를 따라다니는 자유 이동 월드 + HUD + 조이스틱 + 알림 토스트 + 이야기 로그).
- `App.tsx` — 홈 ↔ 마당 화면 전환을 담당하는 최상위 상태 머신.

## 실행하기

```bash
npm install
npx expo start
```

- `w`를 눌러 웹으로 빠르게 확인 가능
- 실기기/에뮬레이터는 Expo Go 또는 `npx expo run:android` / `run:ios` 사용
